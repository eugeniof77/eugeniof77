# Hey, I'm Eugenio 👋
 
CEO at [Osome](https://osome.com), the AI company management platform helping founders run their business across borders without drowning in admin.
 
Italian. Singapore since 2011. Previously co-founded Casa Mia Coliving (exited).
 
**What I actually believe:** AI Speed + Human Nuance. The boring, repetitive work (the rearview mirror) belongs entirely to machines. The judgment calls that someone has to be accountable for (the windshield) stay human. Most "AI-powered" software still just hands you a dashboard and calls it a day. We build service-as-a-software instead: the outcome delivered, not another tool to operate yourself.
 
I'm not an engineer by trade, but I write code where it pays off: GTM tooling and internal experiments at Osome and Casa Mia, and the data stack behind a side project.

### Side project: Expat Living Italia

[expatliving.it](https://www.expatliving.it) is a data-backed publication for people moving to or retiring in Italy, written by my wife Caitlin. I run the data and systems behind it: housing prices, taxes, climate, healthcare and safety for Italy's 7,894 comuni, provinces and regions, with every figure carrying its source and date.

- 📊 [expatliving-data](https://github.com/eugeniof77/expatliving-data): the open data behind the site, as plain JSON and synced from it
- 🔌 [Public API](https://www.expatliving.it/api/docs) plus an MCP server, so AI agents can query the numbers directly
